Linux File Permissions Lab (Ubuntu + VirtualBox)

This lab explores how Linux manages files and directory perms using common Linux commands. The goal of this lab was to gain hands on experience with Linux access control and understand how permissions affect file security and user access.

>

Lab Environment

Before testing file permissions, I first used my controlled Linux environment using virtualization.

  • Host OS: Windows
  • Virtualization: Oracle VirtualBox
  • Guest OS: Ubuntu 24.04 LTS

Creating the Lab Directory

To begin the lab, I created a dedicated working directory called: mkdir fileperms_lab

Then I navigated into the directory using cd fileperms_lab

Creating a separate directory helps organize files thats used during the lab and prevents accidental modification of other files in the system.
